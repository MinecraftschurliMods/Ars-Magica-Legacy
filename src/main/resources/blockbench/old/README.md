GeckoLib changed the format of their Blockbench plugin, requiring a conversion to the new format. This worked nicely for the most part, however they dropped the `easing` properties on some of the keyframes. This is a Blockbench bug that has been reported as [#3457](https://github.com/JannisX11/blockbench/issues/3457). Once the issue is resolved, the old models need to be converted again and the animations re-exported; once that is done, this folder and its contents can be deleted.
